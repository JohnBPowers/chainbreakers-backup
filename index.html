CHAINBREAKERS Backup

CHAINBREAKERS Backup is a private, personal application. Its only purpose is to copy encrypted backups of the owner's own game servers to the owner's own Google Drive. It is not offered to the public, has no other users, and is not a commercial product.

Privacy Policy

Last updated: October 2026

Who uses this application

Only its owner. No one else is invited or permitted to use it.

What Google data it accesses

The application requests only the Google Drive drive.file permission. That permission allows it to create files in the owner's Google Drive and to see or manage only the files it has created itself. It cannot see, read, change or delete any other file in the owner's Google Drive, and it does not access email, contacts, calendar, photos or any other Google service.

What it does with that data

It uploads game server backup files, which are encrypted before they leave the owner's computer, to a single folder in the owner's Google Drive, and periodically downloads one back to confirm backups can be restored. It deletes backups it previously uploaded once they pass the owner's chosen retention period.

What it does not do

  • It does not collect, store or transmit personal information to the developer or any third party.
  • It does not sell, share, rent or disclose any data.
  • It does not use data for advertising, analytics, profiling or machine-learning training.
  • It does not use cookies or tracking of any kind.

Where data is stored

Backups are stored only in the owner's own Google Drive, in encrypted form. The credentials that let the application reach Google Drive are stored only on the owner's own computer, readable by administrators only.

Revoking access

Access can be withdrawn at any time from the owner's Google Account under Security → Third-party apps with account access. Revoking access stops all further uploads immediately.

Compliance with Google policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this application can be sent to the support email listed on its Google consent screen.
